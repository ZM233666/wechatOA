# 小程序前端功能模块清单（讨论稿）

用于梳理当前小程序的功能分级与归属关系，便于评审与排期讨论。

- 范围：小程序主包前端（共 28 个页面，无分包）
- 分级约定：
  - **一级**：底部 Tab（产品主模块）
  - **二级**：一级下的页面或功能域
  - **三级**：二级下的子页面 / 功能区块
  - **四级**：三级下的具体能力点（如有）

## 状态图例

|------|------|

## 1. Home（一级）

对外品牌与内容门户。入口页为首页，再下钻到新闻、品牌、产品、案例。

### 1.1 首页（二级）· ⏳ 占位中

品牌门户首页，聚合展示与入口导航。

| 三级模块 | 状态 | 说明 / 下属能力（四级） |
|----------|------|-------------------------|
| Banner 轮播 | ⏳ | 自动播放；点击跳转新闻或站内页 |
| 快捷入口 | ⏳ | 新闻中心、品牌介绍、产品、案例 |
| 最新资讯 | ⏳ | 列表预览；「更多」进入新闻中心；点击进详情 |

### 1.2 新闻中心（二级）· ✅ 已实现

从首页快捷入口或「最新资讯 · 更多」进入。

| 三级模块 | 状态 | 说明 / 下属能力（四级） |
|----------|------|-------------------------|
| 搜索 | ✅ | 按标题、摘要、标签关键词检索 |
| 分类筛选 | ✅ | 横向分类切换 |
| 新闻列表 | ✅ | 分页加载；置顶 / 精选标记 |
| **新闻详情**（三级页面） | ✅ | 封面与元信息；正文阅读；收藏；微信分享 |

> 层级关系：**首页 → 新闻中心 → 新闻详情**

### 1.3 品牌介绍（二级）· ⏳ 占位中

从首页快捷入口进入，单页展示。

| 三级模块 | 状态 | 说明 |
|----------|------|------|
| Hero 形象区 | ⏳ | 品牌主视觉 |
| 集团简介 | ⏳ | 文字介绍 |
| Vision / Values | ⏳ | 愿景与价值观 |
| Core Brands | ⏳ | 核心品牌标签 |

### 1.4 产品（二级）· ⏳ 占位中

从首页快捷入口进入产品分类页。

| 三级模块 | 状态 | 说明 / 下属能力（四级） |
|----------|------|-------------------------|
| Hero 轮播 | ⏳ | 产品主题轮播 |
| 产品搜索 | ⏳ | 按产品号、名称、参数等过滤 |
| 分类磁贴 | ⏳ | 进入对应产品详情 |
| 联系我们 | ⏳ | 商务联系入口 |
| **产品详情**（三级页面） | ⏳ | 分类介绍；Core Products；富文本；可跳转 Services / 案例 |

> 层级关系：**首页 → 产品分类 → 产品详情**

### 1.5 案例（二级）· ⏳ 占位中

从首页快捷入口进入案例列表。

| 三级模块 | 状态 | 说明 / 下属能力（四级） |
|----------|------|-------------------------|
| 案例列表 | ⏳ | 卡片浏览 |
| **案例详情**（三级页面） | ⏳ | 封面；背景与方案；富文本；收藏 |

> 层级关系：**首页 → 案例列表 → 案例详情**

## 2. Services（一级）

数字化服务与 KB Insights。入口页为服务主页，洞察可页内打开，也可走独立列表 / 阅读 / 无权限页。

### 2.1 服务主页（二级）

| 三级模块 | 状态 | 说明 / 下属能力（四级） |
|----------|------|-------------------------|
| 服务 Hero | ⏳ 占位中 | 服务主题卡片；点击进入服务详情 |
| KB Insights | ✅ 已实现 | 封面网格；「探索更多」展开全量列表；有权限则页内阅读；受限则跳转无权限页 |
| Ask me | ⏳ 占位中 | 问答入口 |

### 2.2 洞察列表（二级 · 独立页）· ✅ 已实现

可从分享、外链或主页「探索更多」路径进入，与主页页内列表能力对等。

| 三级模块 | 状态 | 说明 |
|----------|------|------|
| 封面网格 | ✅ | 洞察报告浏览 |
| 权限控制 | ✅ | 按角色决定是否可阅读 |
| 微信分享 | ✅ | 列表页分享 |

### 2.3 洞察阅读（二级 · 独立页）· ✅ 已实现

按报告 ID 打开阅读器；关闭可回退或回到服务主页；支持带 ID 分享。

> 也可在服务主页 / 洞察列表内以页内阅读器形式打开（同能力、不同承载方式）。

### 2.4 无权限提示（二级）· ✅ 已实现

访客访问受限洞察时的拦截页。

| 三级模块 | 状态 | 说明 |
|----------|------|------|
| 无权限说明 | ✅ | 文案提示 |
| 申请权限 | ✅ | 提交申请 |
| 返回 | ✅ | 回到上一页或服务主页 |

> 层级关系示意：
>
> ```
> 服务主页
> ├── 服务 Hero · ⏳ → 服务详情
> ├── KB Insights · ✅
> │   ├── 页内全量列表 · ✅
> │   ├── 洞察阅读（页内 / 独立页）· ✅
> │   └── 无权限提示 · ✅
> └── Ask me · ⏳
> ```

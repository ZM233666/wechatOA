# 新闻编辑指南

面向未来内容编辑。当前仓库用 JSON Fixture 模拟 CMS 发布结果，填写方式应与将来 CMS 输出一致。这不是 CMS 产品说明书。

## 标题

- 一屏可读完，建议 40 字以内，英文标题可略长，不超过 160 字符。
- 不写无法验证的绝对化宣传。
- 不把关键词堆进标题。

## 摘要

- 用于首页、列表和分享，建议 40–80 字，不超过 220 字符。
- 写清事件与价值，不要复制整段正文。

## 封面图

- 建议 16:9（例如 1200×675）。
- 必须提供 `alt`、`width`、`height`、`aspectRatio`。
- 路径使用 `/mock-assets/news/...`，不要写 `127.0.0.1`。

## 正文图片

- 与封面分开存储。
- 建议 3:2 或接近阅读宽度的横向图。
- 必须有图片说明 `caption`。
- `layout` 只用 `normal` / `wide` / `full`。

## 标题层级

- 文章主标题用页面 `title`，不要在正文再放一个 H1 作为页面标题的替代信息架构。
- 正文使用 H2 划分章节，H3 为小节。
- 不要跳级。

## 段落

- 一段一个意思，避免超长墙文。
- 加粗只用于关键术语，不要整段加粗。
- `align` 默认 left。

## 引用

- 用于观点或原则性表述。
- 注明 `source`。
- 不要虚构未确认的政府合作或具体合同金额。

## 列表

- 无序列表用于要点。
- 有序列表用于步骤或交付顺序。

## Callout

- `info`：补充说明。
- `warning`：阅读或操作注意。
- `exclusive`：精选提示，小程序用有限金色点缀。
- 不要靠 Callout 堆砌营销口号。

## 内部链接

- 只允许小程序页面路径，例如 `/pages/products/detail?id=product-001`。
- 不要把 `__scenario` 放进链接。

## 外部链接

- 仅 `http` / `https`。
- 禁止 `javascript:` 和其他伪协议。
- 当前小程序不会直接打开外部网页。

## 相关阅读

- 填写已存在文章 ID，不能关联自身。
- 公开端最多展示 3 条，且只展示已发布可见文章。

## 分享

- `share.title` 短于正文标题更好。
- `share.imageUrl` 建议单独裁切的分享图；没有时回退封面。

## 不允许的内容

- 任意 HTML、inline style、className、script、iframe、onclick。
- 虚构合同金额、未经确认的政府合作、具体安全事故。
- 真实个人隐私。
- 无法验证的绝对化宣传。
- 把公众号后台 HTML 原样粘进 JSON。
